# Synthetic demo data provenance

Every input in `examples/demo/data/` is newly generated synthetic material.
No patient, clinical, Xenium, BC1, BC2, melanoma, human-breast, GHIST tutorial,
or other research-sample data was read, copied, cropped, transformed, measured,
or statistically summarized to create it.

The committed files were generated by `scripts/generate_synthetic_demo.py`
using fixed seed `20260813` and Python standard-library algorithms. The script
accepts only an output directory: it has no source-dataset argument, network
access, model loading, encoder call, or checkpoint input.

## Contents

| Property | Synthetic value |
|---|---:|
| Histology/mask extent | 768 × 768 pixels |
| Histology representation | uint8 RGB baseline TIFF |
| Mask representation | uint32 label TIFF; 0 is background |
| Cells | 96, IDs 1–96 |
| Genes | 24 (`synthetic_gene_01`–`synthetic_gene_24`) |
| Cell types | 4 (`synthetic_type_a`–`synthetic_type_d`) |
| Training patches | 6 |
| Validation patches | 4 |
| Feature rows | 10 |
| Feature dimension | 1024 |
| Feature dtype | float16 |

Synthetic nuclei are non-overlapping ellipses on a generated color texture.
Raw non-negative integer expression counts combine seeded noise with synthetic
type and coordinate terms solely to avoid a degenerate all-constant matrix.
These values do not represent genes, tissues, patients, disease mechanisms, or
biological measurements.

`data/uni/uni_features.npy` contains deterministic synthetic precomputed
morphology features matching the HistCFM feature interface. Despite the formal
loader filenames, these numbers are **not** UNI-derived embeddings and were not
produced by UNI, UNI2, another foundation model, or any third-party model. The
repository contains no UNI code, checkpoint, weights, or output in this demo.

The optional synthetic end-to-end smoke test exists only to exercise configuration parsing, data
validation, training, checkpoint creation, inference, and evaluation through
the formal HistCFM commands. It is not suitable for biological interpretation,
model-quality assessment, paper-metric reproduction, or comparison with real
experiments.
